# Notes & User Preferences

- **Teaching Style**: Interactive guided coding. **Show the user what to type, explain each piece, and let the user make the changes and run the tests themselves.** Do not auto-write code unless specifically asked.
- **Learning goal**: Pragmatic Go development, moving at a productive pace while building deep muscle memory and understanding.
- **Provider privacy**: `mangadistrict` and private providers live under `internal/providers/private/` (gitignored). Refer to private sources strictly with the term "private".
- **Integration target**: Dewey (`~/Dev/dewey`) via headless CLI JSON commands.
- **Testing preference**: High-seam tests (real HTTP fixtures and round-trippers) over tedious mock-heavy unit tests.
