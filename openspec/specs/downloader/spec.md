# Downloader Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:16

## Purpose

Manages chapter and page downloads with per-provider concurrency throttling, rate-limit backoff
handling, and library destination path resolution.

## Requirements

> `internal/downloader/downloader.go`

### Requirement: ResolveDestinationPath

The system SHALL the service shall resolve the destination .cbz archive file path for a chapter by inspecting the library directory structure and sanitizing names.

#### Scenario: ResolveValidChapterArchivePath
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A valid series, chapter metadata, and target download options
- **WHEN** ResolveDestinationPath is invoked
- **THEN** A sanitized and structured destination file path ending in .cbz is returned

### Requirement: FetchPageWithRetry

The system SHALL the service shall fetch an individual chapter page image via http, backing off dynamically upon encountering rate limits.

#### Scenario: SuccessfulPageDownload
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** An accessible image page URL and valid request context
- **WHEN** fetchPageWithRetry is called
- **THEN** The downloaded page bytes with detected extension are returned as PageData

#### Scenario: RateLimitBackoffRetry
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A provider returning HTTP 429 or rate-limiting headers
- **WHEN** fetchPageWithRetry is called
- **THEN** The request is delayed according to throttle state and retried until success or context cancellation

### Requirement: AcquireWorker

The system SHALL the service must wait until a worker concurrency slot is available for the provider before incrementing the active worker count.

#### Scenario: AvailableWorkerSlot
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** Active workers are below the provider concurrency limit
- **WHEN** AcquireWorker is called
- **THEN** The active worker count increments and nil error is returned

#### Scenario: ContextCancellationDuringWait
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** All worker slots are saturated and the caller context expires
- **WHEN** AcquireWorker waits for a free slot
- **THEN** The context cancellation error is returned immediately

### Requirement: ReleaseWorker

The system SHALL the service must decrement the active worker count for a provider and notify waiting workers.

#### Scenario: ReleaseActiveWorkerSlot
- **GIVEN** A worker has completed downloading or processing a page
- **WHEN** ReleaseWorker is called
- **THEN** Active worker count decrements and waiting callers are signaled

### Requirement: ProviderWorkers

The system SHALL the service shall return the allowed concurrency worker count for the specified provider based on its current throttle status.

#### Scenario: QueryWorkerCapacity
- **GIVEN** A configured provider ID
- **WHEN** ProviderWorkers is queried
- **THEN** The active worker capacity limit for that provider is returned

### Requirement: IsProviderThrottled

The system SHALL the service shall check whether a provider is currently in a throttled backoff state.

#### Scenario: ProviderIsCurrentlyThrottled
- **GIVEN** A provider that recently triggered rate limiting
- **WHEN** IsProviderThrottled is checked
- **THEN** True is returned indicating active backoff
