# Provider Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:16

## Purpose

Provides a thread-safe registry to register, look up, and list webcomic providers.

## Requirements

> `internal/provider/registry.go`

### Requirement: RegisterProvider

The system SHALL registers a new provider instance in the registry. it must reject nil providers, empty ids, or duplicate provider ids.

#### Scenario: SuccessfulRegistration
<!-- openlore-test: tags=smoke,regression (auto) -->
- **GIVEN** A valid Provider with a non-empty, unique ID
- **WHEN** Register is called
- **THEN** The provider is added to the registry and no error is returned

#### Scenario: NilProvider
<!-- openlore-test: tags=smoke,regression (auto) -->
- **GIVEN** A nil provider reference
- **WHEN** Register is called
- **THEN** An error stating cannot register nil provider is returned

#### Scenario: EmptyProviderID
- **GIVEN** A provider returning an empty string for ID()
- **WHEN** Register is called
- **THEN** ErrEmptyProviderID is returned

#### Scenario: DuplicateProviderID
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** A provider whose ID is already registered in the registry
- **WHEN** Register is called
- **THEN** ErrProviderAlreadyExists wrapped with the provider ID is returned

### Requirement: GetProvider

The system SHALL retrieves a registered provider by its unique id.

#### Scenario: ProviderExists
- **GIVEN** A provider with the specified ID is registered
- **WHEN** Get is called with that ID
- **THEN** The matching Provider and true are returned

#### Scenario: ProviderDoesNotExist
- **GIVEN** No provider with the specified ID is registered
- **WHEN** Get is called with that ID
- **THEN** A nil Provider and false are returned

### Requirement: FindByURL

The system SHALL searches registered providers and returns the first provider that can handle the given url.

#### Scenario: MatchingProviderFound
- **GIVEN** A registered provider whose MatchesURL returns true for the input URL
- **WHEN** FindByURL is called with that URL
- **THEN** The matching Provider and true are returned

#### Scenario: NoMatchingProvider
- **GIVEN** No registered provider whose MatchesURL returns true for the input URL
- **WHEN** FindByURL is called with that URL
- **THEN** A nil Provider and false are returned

### Requirement: AllProviders

The system SHALL returns a slice of all registered providers sorted deterministically by their human-readable name in ascending order.

#### Scenario: ListAllProvidersSortedByName
- **GIVEN** Multiple providers registered in the registry
- **WHEN** All is called
- **THEN** A slice of all providers sorted alphabetically by Name() is returned

### Requirement: ListProviders

The system SHALL acts as an alias for all, returning all registered providers sorted by name.

#### Scenario: ListAliasExecution
- **GIVEN** Providers registered in the registry
- **WHEN** List is called
- **THEN** The identical result as calling All() is returned
