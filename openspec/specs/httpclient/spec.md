# Httpclient Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:16

## Purpose

Validates provider-supplied request URLs to enforce security constraints such as permitted schemes,
hostnames, ports, and absence of credentials or fragments.

## Requirements

> `internal/httpclient/url_policy.go`

### Requirement: Validate

The system SHALL verifies that rawurl is an absolute request url conforming to policy rules, rejecting invalid schemes, credentials, ip literals, mismatched ports, or fragments.
