# Tui Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:16

## Purpose

Manages interactive terminal user interface state, navigation across screens, search queries,
chapter selection, and background download queue coordination.

## Requirements

> `internal/tui/model.go`

### Requirement: InitializeModel

The system SHALL constructs and initializes the standard interactive tui model with default providers and ui components.

#### Scenario: InitializeStandardTUISession
- **GIVEN** A valid provider registry, downloader, and context
- **WHEN** NewModel is called
- **THEN** A Model is returned initialized at the providers screen with preferred providers selected by default

### Requirement: InitializeSelectModel

The system SHALL constructs and initializes the tui model in interactive selection mode for url resolution and direct search.

#### Scenario: InitializeSelectModeWithPrefilledQuery

- **THEN** A Model is returned in selectMode on screenSearch with text input set and loading state enabled

#### Scenario: InitializeSelectModeWithoutQuery

- **WHEN** NewSelectModel is called

### Requirement: CheckCompactLayout

The system SHALL determines whether the terminal viewport requires compact layout rendering.

#### Scenario: NarrowTerminalWidth

- **WHEN** IsCompact is evaluated

#### Scenario: PortraitTerminalDimensions

- **WHEN** IsCompact is evaluated
- **THEN** True is returned

#### Scenario: StandardLandscapeTerminalDimensions

- **WHEN** IsCompact is evaluated
