# Domain Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:16

## Purpose

Parses and resolves chapter numbers and metadata from raw strings, chapter records, and archive
filenames.

## Requirements

> `internal/domain/chapter.go`

### Requirement: ParseChapterNumber

The system SHALL extracts the numeric chapter value from a title or label, stripping season prefixes and handling explicit chapter keywords or fallback numbers.

#### Scenario: TitleWithExplicitChapterKeywordAndSeasonPrefix
- **GIVEN** A title string containing season information and an explicit chapter marker like 'Season 1 Finale -
Chapter 40'
- **WHEN** ParseChapterNumber is called with the title string
- **THEN** It MUST return a pointer to float64 value 40.0

#### Scenario: TitleWithoutAnyChapterNumbers
- **GIVEN** A title string containing no numeric values
- **WHEN** ParseChapterNumber is called with the title string
- **THEN** It MUST return nil

### Requirement: GetEffectiveChapterNumber

The system SHALL calculates the effective numeric chapter value for comparison by prioritizing explicit chapter number, parsed title, parsed original label, or falling back to index.

#### Scenario: ChapterHasExplicitNumberSet
- **GIVEN** A Chapter object with Number property set to 15.5
- **WHEN** ChapterNumber is called with the Chapter
- **THEN** It MUST return 15.5

#### Scenario: ChapterNumberMissingButTitleContainsNumber
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** A Chapter object with nil Number and Title 'Chapter 5'
- **WHEN** ChapterNumber is called with the Chapter
- **THEN** It MUST return 5.0

#### Scenario: ChapterNumberAndTitle/labelUnparseable
- **GIVEN** A Chapter object with nil Number, unparseable Title and OriginalLabel, and Index 3
- **WHEN** ChapterNumber is called with the Chapter
- **THEN** It MUST return the Index as a float64 (3.0)

### Requirement: ParseChapterNumberFromFilename

The system SHALL extracts the chapter number from a cbz/zip filename, handling bracket index prefixes, explicit chapter naming conventions, and fallbacks.

#### Scenario: FilenameWithBracketPrefixAndExplicitChapterMarker
- **GIVEN** A filename formatted like '[0001]_Chapter_99_-[End].cbz'
- **WHEN** ParseChapterNumberFromFilename is called with the filename
- **THEN** It MUST parse and return 99.0

#### Scenario: FilenameWithOnlyBracketPrefixIndex
- **GIVEN** A filename formatted like '[0045].cbz'
- **WHEN** ParseChapterNumberFromFilename is called with the filename
- **THEN** It MUST parse and return 45.0
