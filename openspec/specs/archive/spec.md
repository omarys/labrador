# Archive Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:16

## Purpose

Encapsulates the packaging and generation of comic book archives (CBZ) including ComicInfo XML
metadata generation for downloaded chapters.

## Requirements

> `internal/archive/cbz.go`

### Requirement: WriteCBZ

The system SHALL the service shall bundle manga chapter pages and accompanying comicinfo metadata xml into a valid cbz (zip) archive at the specified target file path.

#### Scenario: SuccessfullyWriteCBZArchive
<!-- openlore-test: tags=smoke,regression (auto) -->
- **GIVEN** A valid target file path, series and chapter metadata, and a non-empty list of page data
- **WHEN** WriteCBZ is invoked
- **THEN** A CBZ archive containing ComicInfo.xml and page images is created at targetPath and returns nil
error

#### Scenario: TargetDirectoryCreationFailure
<!-- openlore-test: tags=smoke,regression (auto) -->
- **GIVEN** A target path whose parent directory cannot be created or accessed due to permissions
- **WHEN** WriteCBZ is invoked
- **THEN** The operation returns a non-nil error and leaves no corrupted archive at the target path

### Requirement: GenerateComicInfo

The system SHALL the service shall build xml-formatted comicinfo metadata bytes containing series details, chapter information, and total page count.

#### Scenario: GenerateValidComicInfoXML
<!-- openlore-test: tags=smoke,regression (auto) -->
- **GIVEN** Valid series and chapter metadata and an integer page count
- **WHEN** GenerateComicInfo is invoked
- **THEN** Marshaled XML bytes corresponding to the ComicInfo schema are returned with nil error
