# Cli Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:16

## Purpose

Encapsulates CLI command parsing, subcommand dispatching, and orchestration between providers,
downloaders, and terminal user interfaces.

## Requirements

> `internal/cli/cli.go`

### Requirement: Run

The system SHALL parse command line arguments and dispatch execution to the corresponding subcommand handler or display usage instructions.

#### Scenario: DispatchKnownSubcommand
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** A valid subcommand argument like 'search' or 'fetch'
- **WHEN** Run is called with the arguments
- **THEN** Execution is routed to the corresponding subcommand handler without error

#### Scenario: NoArgumentsProvided
- **GIVEN** Empty arguments list
- **WHEN** Run is called
- **THEN** Usage instructions are printed to standard output

#### Scenario: UnknownSubcommand
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** An unrecognized subcommand argument
- **WHEN** Run is called
- **THEN** An error is returned indicating the invalid command and usage is shown

### Requirement: RunSearch

The system SHALL execute search queries across configured providers and display matching results in text or json format.

#### Scenario: SearchWithQueryString
- **GIVEN** A query string and valid provider flags
- **WHEN** runSearch is executed
- **THEN** Providers are queried and matching titles are written to output

#### Scenario: MissingQueryArgument
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** Command arguments lacking a search query
- **WHEN** runSearch is executed
- **THEN** An error is returned describing the missing query argument

### Requirement: RunFetch

The system SHALL locate the specified chapter from a provider and download chapter content using the downloader service.

#### Scenario: DownloadExistingChapter
- **GIVEN** A valid provider and chapter number/identifier
- **WHEN** runFetch is executed
- **THEN** The chapter is retrieved and downloaded via the downloader service

#### Scenario: ChapterNotFound
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** A chapter identifier that does not exist on the target provider
- **WHEN** runFetch is executed
- **THEN** An error is returned indicating the chapter could not be located

### Requirement: RunBrowse

The system SHALL query provider catalogs for available items and display the catalog results in text or json format.

#### Scenario: BrowseProviderCatalog
- **GIVEN** A valid provider supporting browse capabilities
- **WHEN** runBrowse is executed
- **THEN** Catalog items are retrieved from the provider and rendered

### Requirement: RunProviders

The system SHALL list all registered providers along with their identifiers, names, and supported capabilities.

#### Scenario: ListProviders
- **GIVEN** A registry containing one or more providers
- **WHEN** runProviders is executed
- **THEN** A summary or JSON list of providers and their capabilities is written to output

### Requirement: RunResume

The system SHALL read persisted download queue state from disk and resume downloading remaining items.

#### Scenario: ResumeActiveQueue
- **GIVEN** A valid queue cache file containing pending downloads
- **WHEN** runResume is executed
- **THEN** Pending items are downloaded and the queue file is updated or removed upon completion

#### Scenario: NoQueueCacheFilePresent
- **GIVEN** Absence of a queue cache file
- **WHEN** runResume is executed
- **THEN** A notification is printed indicating no pending downloads exist

### Requirement: RunSelect

The system SHALL launch an interactive terminal selection model for choosing chapters or search results.

#### Scenario: LaunchInteractiveSelector
- **GIVEN** Query arguments or search context
- **WHEN** runSelect is executed
- **THEN** The Bubbletea TUI selection interface starts and captures user choices

### Requirement: RunChapters

The system SHALL list available chapters for a specified work from the targeted provider.

#### Scenario: ListWorkChapters
- **GIVEN** A valid work identifier or URL and provider
- **WHEN** runChapters is executed
- **THEN** The list of chapters is retrieved and output in text or JSON format

### Requirement: RunOpen

The system SHALL open a work or url directly into the interactive chapter browsing tui.

#### Scenario: OpenURLInTUI
- **GIVEN** A valid target URL or series name
- **WHEN** runOpen is executed
- **THEN** The chapter browser TUI program is initialized and launched
